# 小说阅读器 HarmonyOS

小说阅读器（NovelReader）的 HarmonyOS 版本，基于 ArkTS 与 ArkUI 开发，并持续同步 Android 版的主要功能与使用体验。

- 当前版本：`1.2.5`（`versionCode 1020500`）
- Bundle Name：`com.wjnocal.novelreader`
- 支持设备：HarmonyOS 手机、平板
- Android 版本：[wjnocal/NovelReader](https://github.com/wjnocal/NovelReader)

## 1.2.5 更新重点

- 新增华为官方沉浸光感：书架/主页底部导航及阅读页底部菜单使用悬浮玻璃材质，并提供系统交互光效。
- 新版沉浸光感需要设备更新至 **HarmonyOS 7.0 及以上**，且设备支持并启用该系统材质；旧系统或不支持材质的设备使用兼容界面。

## 1.2.0 更新重点

本次更新对照 Android `3.300` 的功能改进，参考提交 `207bae23c4be58cea898bdf1d87fb38d761db3a7`（2026-10-11），并完善鸿蒙端的深色模式和搜书异常处理。

- 在线下载支持边下边看：首章完成后即可从下载卡片、后台任务通知或书架打开本地阅读器，后续章节按目录顺序追加，保持当前阅读位置。
- 取消或失败后保留已下载章节；重新选择相同书源、格式和目录可继续下载。完整章节缓存会校验 SHA-256，过期或损坏时重新抓取。
- 未完成的书籍暂不上传至 WebDAV；完整下载并生成 TXT/EPUB 后恢复同步。
- 搜索最多同时查询 4 个书源，结果保持书源顺序；改善请求调度、取消响应和 HTTP 限流退避。
- 更新 25 个内置书源配置，补齐搜索 Cookie、独立搜索间隔、搜索/目录/正文分页及 XPath 规则；笔趣阁22原域名已失效，暂时停用。
- 修复多书源选择弹窗在小屏幕上无法显示全部选项的问题。
- 修复系统深色模式下输入文字与浅色背景冲突：书架、主页、在线搜书、浏览器和弹窗统一适配深色配色，页面与阅读背景变黑；切回浅色时恢复原阅读主题。
- 修复搜书遇到失效书源后停留在错误提示的问题：结果实时显示，404/403 不重试，分页失败保留已有结果；单次请求、单书源、整轮搜索的等待上限分别为 8 秒、20 秒、60 秒，可随时停止搜索并保留结果。
- 改善请求取消、HTTP 限流退避、字符编码识别、Base64 正文处理及多页章节边界，避免将下一章拼接进当前章或缓存残缺正文。
- 实时搜索结果重排时保持下载来源弹窗对应的书籍；后台追加章节和保存阅读进度时保留最新下载状态，避免旧页面数据覆盖新章节。

## 功能

- 本地导入 TXT、EPUB 小说
- 自动解析中英文常见章节标题，支持 EPUB 2 NCX 与 EPUB 3 Navigation 目录
- 重复导入或重复下载同名同作者书籍时更新内容，并保留书架实体和阅读进度
- 滚动阅读与滑动翻页阅读
- 字号、行距、页边距及阅读主题设置
- 目录、书签、笔记和文本标记
- 书架网格/列表展示、搜索、排序、分类、置顶和改名
- 阅读时长、连续阅读天数及每日阅读目标统计，切入后台时自动保存本次阅读
- 多书源在线搜书、同名结果聚合、来源选择及 TXT/EPUB 下载
- 目录分页、章节正文多页解析、失败重试、限流调度和后台下载
- 内置小说浏览器，支持网址或关键词访问、前进后退、刷新和加载进度，可将当前章节直接切换为净化阅读模式
- 在线阅读支持书源规则匹配、通用正文识别、广告文本过滤、章节内多页续接和跨章节跳转
- 在线阅读与本地阅读保持一致的分页/滚动、手势、菜单、字号、行距、页边距和主题设置
- WebDAV 双向同步书籍、进度、书签、笔记与阅读统计，包含删除同步和并发冲突保护
- 本地数据备份与幂等恢复（同名书合并，书签和笔记去重）
- 手机、平板及横屏布局适配

## 开发环境

- DevEco Studio `26.0.0`（本地验证版本 `26.0.0.851`）
- HarmonyOS SDK `26.0.0 (API 26)`
- 最低兼容版本 `6.1.0 (API 23)`
- ArkTS / ArkUI

阅读页顶部与底部复用 API 26 官方悬浮材质容器，返回键与书名分别显示在圆形、胶囊形背板中。点击书名仅产生系统光感反馈，不执行跳转等操作；菜单呼出时覆盖正文，不为菜单额外留白。旧系统使用深浅色适配的普通背板。

主页和本地阅读页底部导航在 API 26 上使用原生 `Tabs.barFloatingStyle` 与 `uiMaterial.ImmersiveMaterial`，提供新版系统交互光效；API 23–25 保留原有官方 HDS 悬浮导航。

## 运行项目

1. 使用 DevEco Studio 打开项目目录。
2. 等待工程同步及依赖初始化完成。
3. 在项目结构的“签名配置”中选择或生成自己的调试签名。
4. 连接 HarmonyOS 手机、平板或模拟器。
5. 运行 `entry` 模块。

首次运行后可从主页导入本地 TXT/EPUB，或进入“在线搜书”选择书源搜索和下载小说。

也可从“主页 → 内置浏览器”访问小说站点，在具体章节页点击右下角“在线阅读”进入正文模式。在线模式适合临时阅读；需要长期保存、添加书签或同步阅读数据时，建议通过在线搜书下载到书架。

## WebDAV 同步

在“主页 → WebDAV 同步”中填写服务器地址、用户名和密码，测试连接成功后即可执行双向同步。

同步目录及数据格式与 Android 版本保持兼容，默认使用：

```text
NovelReaderSync/manifest.json
```

建议首次同步前备份本地数据，并避免两台设备同时修改同一本书的阅读数据。

同步清单使用 ETag 条件写入；如果发布前服务器数据已被其他设备更新，本次同步会停止并提示重试，避免静默覆盖。

## 在线搜书

在线搜书内置 25 个参考 [wjnocal/NovelReader](https://github.com/wjnocal/NovelReader) 安卓版的书源配置，底层规则参考 [freeok/so-novel](https://github.com/freeok/so-novel)。失效书源会停用并标注原因（当前包括笔趣阁22）。可在搜索前自行选择书源；来自不同书源的同名同作者小说会合并为一项，点击后再选择具体来源和 TXT/EPUB 下载格式。

当前规则适配 CSS 选择器、动态搜索参数、JSONP 搜索结果、Base64 正文、`data-id` 段落重排及脚本分页。书源仍可能因目标网站结构、Cloudflare、代理要求或网络环境变化而失效。

搜索结果逐页显示，遇到 404/403 等错误直接跳过对应请求；后续搜索页失败不会丢弃已找到的结果。单次搜索请求最多等待 8 秒，单书源搜索最多 20 秒，整轮搜索最多 60 秒。点击“停止搜索”可立即停止并保留当前结果；重新搜索不会被上一轮迟到的回调覆盖。

下载过程会遵守各书源配置中的请求间隔，并支持目录分页、章节多页正文合并、失败重试和安全的并发加速。后台任务使用 HarmonyOS `dataTransfer` 模式；系统省电策略、网络限制或书源限流仍可能影响下载速度。

首章完成后可点击下载卡片的“立即阅读”，也可直接从书架进入。读到尚未下载的章节时会提示等待；取消或下载失败后仍可阅读已完成部分，选择原书源和格式即可继续。为保证章节顺序，目录或解析规则发生变化时不会将旧的未完成内容与新的下载混合。

## 内置浏览器与在线阅读

内置浏览器支持输入完整网址或搜索关键词，并提供后退、前进、刷新和加载进度。打开小说章节网页后，点击“在线阅读”可提取标题与正文，过滤常见广告内容并进入净化阅读界面。

在线阅读器会优先使用匹配书源的正文与导航规则，并在没有匹配规则时使用通用网页识别。它可以识别中文或英文的上一章、下一章、上一页、下一页按钮，以及常见的 `rel`、ID、class 导航标记。若一章被网站拆成多页，会先合并下一页正文，读完后才进入下一章，并避免重复链接造成循环跳转。

分页模式下可以点击屏幕左右区域或横向滑动翻页，点击中间区域呼出/隐藏阅读菜单；滚动模式下也会在阅读时隐藏菜单。字号、行距、页边距和主题设置与本地阅读器保持一致。

应用需要以下网络权限：

```text
ohos.permission.INTERNET
ohos.permission.KEEP_BACKGROUND_RUNNING
```

## 数据说明

书籍解析结果、阅读进度、书签、笔记和设置保存在应用沙箱中。卸载应用可能清除这些数据，请提前使用备份或 WebDAV 同步功能保存。

书架主数据和章节数据采用临时文件替换写入；主数据损坏时会尝试读取最近一次可用备份。

## 验证

- 运行 `node scripts/test-bottom-navigation.cjs` 和 `node scripts/test-reader-navigation.cjs`，检查主页、阅读底栏的 API 26 原生材质接入、旧系统分支和导航交互。
- 运行 `node scripts/test-reader-top-controls.cjs`，检查新版 SDK 配置、顶部独立控件、摄像头避让及旧系统材质回退。沉浸光感的实际外观仍需 HarmonyOS 真机验证。
- 运行 `node scripts/test-color-mode.cjs`，检查深浅色资源、输入框配色和深色对比度；阅读主题逻辑同时纳入鸿蒙单元测试。仍需真机验证系统切换和网页深色效果。
- 在安装 Node.js 和 TypeScript 的环境运行 `node scripts/test-online-download.cjs`，验证本地模拟书源下的边下边看、续传、取消、缓存校验和多页边界。若无法自动找到 TypeScript，可用 `TYPESCRIPT_PATH` 指定其安装路径。
- 在 DevEco Studio 的 Hvigor 任务中运行 `entry:test` 执行本地单元测试。
- 运行 `entry:assembleHap` 生成调试 HAP。
- 为避免测试产物与打包产物争用源映射文件，请按上述顺序串行执行两个任务。
