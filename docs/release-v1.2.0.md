## v1.2.0 更新内容

- 同步 Android 3.300 的主要功能改进，更新 25 个内置书源配置；笔趣阁22原域名已失效，暂时停用。
- 新增边下载边阅读：首章完成即可从书架、下载卡片或后台通知打开阅读器，后续章节按目录顺序追加，并保持当前阅读位置。
- 支持下载失败或取消后保留已完成章节，选择相同书源、格式和目录可继续下载；新增完整章节缓存与 SHA-256 校验。
- 优化在线搜书：最多并发查询 4 个书源，结果实时显示，失败书源自动跳过；支持停止搜索，并保留已找到的结果。
- 修复搜书停留在 HTTP 404 提示的问题，增加请求、单书源及整轮搜索超时；后续搜索页失败不再丢失已有结果。
- 完善章节多页合并、分页边界、字符编码和 Base64 正文处理，改善网络请求取消与限流退避，避免拼接到下一章或缓存残缺正文。
- 完善系统深色模式：书架、主页、在线搜书、浏览器、输入框和弹窗同步使用深色配色，页面与阅读背景变黑；切回浅色时恢复原阅读主题。
- 改善下载状态与阅读进度保护，未完成书籍暂不上传 WebDAV，完整下载后恢复同步；修复书源选择弹窗显示及实时搜索结果重排时的来源选择问题。
